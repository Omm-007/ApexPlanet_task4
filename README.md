# ApexPlanet Internship – Task 4
## PHP & MySQL – Security Enhancements

### Project Overview
This project is Task 4 of my Web Development Internship at ApexPlanet Software Pvt. Ltd.

The objective of this task is to improve the security of the existing PHP and MySQL blog application by implementing important security features and following secure coding practices.

### Features
- Secure User Authentication
- Password Hashing using PHP
- Session Management
- User Authorization
- Protection against SQL Injection using PDO Prepared Statements
- Input Validation and Sanitization
- Secure Post Management
- Access Control for Edit and Delete Operations
- Improved Application Security

### Installation & Setup
1. Install XAMPP.
2. Clone this repository into the `htdocs` folder.
3. Start Apache and MySQL from XAMPP Control Panel.
4. Open phpMyAdmin.
5. Create the required database and import `database.sql`.
6. Configure the database connection in `config.php`.
7. Open the project in your browser:

```text
http://localhost/ApexPlanet_Task4/
```
